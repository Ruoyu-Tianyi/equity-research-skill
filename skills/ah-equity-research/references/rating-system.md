# 投资评级体系

默认采用国际大型投行通行的三档股票评级（买入／中性／卖出，对应 Buy / Neutral / Sell）和三档行业评级（超配／标配／低配，对应 Overweight / Neutral / Underweight）。评级由目标价推出，不能单独选择。用户提供自有评级体系时，以用户体系为准，并替换报告末尾的评级说明。

## 股票评级

| 评级 | 定义（报告发布日后12个月） |
|---|---|
| 买入（Buy） | 预期总回报相对基准指数超额收益 ≥ +10% |
| 中性（Neutral） | 预期总回报相对基准指数超额收益介于 -10% 与 +10% 之间 |
| 卖出（Sell） | 预期总回报相对基准指数超额收益 ≤ -10% |

- 预期总回报 = 目标价 / 当前股价 − 1 + 预期股息率；超额收益 = 预期总回报 − 基准指数预期回报（无可靠依据时取0，并在底稿说明）。
- 基准：A股沪深300（科创板可用科创50），港股恒生指数。
- 目标价为12个月目标价，来自报告正文的估值方法（如DCF每股价值、目标倍数×目标年度利润）；正文须写明方法、取值与对应的涨跌幅。估值基准日价值与12个月目标价不一致时，说明是否滚动以及滚动方式。
- 评级变动标注：首次覆盖／维持／上调／下调。

## 行业评级

| 评级 | 定义（未来12个月） |
|---|---|
| 超配（Overweight） | 行业基本面与估值吸引力优于基准指数，建议高于市场权重配置 |
| 标配（Neutral） | 行业表现预计与基准指数基本一致 |
| 低配（Underweight） | 行业表现预计弱于基准指数，建议低于市场权重配置 |

## 在报告中的呈现

- 封面左栏顶部：评级框（如“卖出（首次覆盖）”）、12个月目标价、当前股价、预期回报。
- 投资要点末条与估值章节：一句话给出评级、目标价、方法与触发上调／下调的条件。
- 报告末尾：投资评级说明表与重要声明（`build_report.py`自动生成）。

## 规格与检查

```json
"rating": {"rating": "卖出", "change": "首次覆盖", "target_price": 514.0,
           "benchmark": "科创50", "benchmark_return": 0.0, "dividend_yield": 0.0}
```

- 缺少目标价或当前股价时报错；所给评级与目标价推出的评级不一致时报错（例如超额收益为-17.7%却写“中性”）。
- 不出具评级时写 `"rating": false`；未设置时给出警告。
- 不借用任何券商的评级名称体系之外的专有用语、标识或免责声明原文。
