# 研究底稿：写作前的论证关卡

研究底稿 `research-brief.md` 是正文的唯一论证来源。在任何章节写作、图表装配之前完成；写作阶段只能展开底稿中的论点，不能临时新增未经底稿检验的核心判断。底稿保存在support，不进入成稿。

底稿的目的不是填表，而是逼出三件事：**这家公司现在最值得回答的问题是什么、市场现在怎么看、我们为什么看法不同（或相同）以及凭什么**。

## 1. 核心研究问题（1个，最多2个）

用一句话写出决定投资判断的问题，必须具体到公司、变量和时间。

- 合格：“新一代产品放量与大客户导入，能否让公司在未来两年把单位毛利维持在行业上行期的高位，而不是随价格回落迅速回吐？”（实际使用时写出具体产品、客户类别和年份）
- 不合格：“公司能否持续成长”“行业景气如何演绎”——换公司名仍成立。

## 2. 市场定价与预期差

先回答“现价已经反映了什么”，再谈我们的判断。按可得性依次使用：

1. 有日期、有样本数的一致预期（收入/利润/目标价）；
2. 现价反推：在模型框架内固定其余变量，求解现价对应的关键经营变量（如2027E净利、终值倍数、毛利率）；
3. 可比公司当前倍数与本公司隐含倍数。

远期PE折现类估值可用`scripts/reverse_valuation.py`的`implied_pe_anchor`同时得到基准价值、现价隐含利润与隐含倍数；其他模型用`solve`对单一变量二分求解，并在底稿记录固定的其他变量。

写出 **预期差陈述**：“现价隐含X，我们的模型/证据指向Y，差异主要来自Z变量。”若我们的结论与市场接近，如实写“预期差有限”，报告重心转向风险收益与催化，而不是制造分歧。无现价或无法反推时，记录缺口，正文不得出现“市场低估/高估”。

**大幅偏离检查**：基准价值与现价偏离超过±30%时，必须在底稿里列出至少两种“市场可能是对的”解释（如周期顶点盈利、远期年份不确定、稀释、流动性/解禁、治理折价），逐条说明为何不足以推翻或如何已在情景中体现。答不上来则下调结论强度或修正估值展示，而不是保留数字。

## 3. 论点卡（3–5张）

每张卡对应正文一个主要论点，按以下字段填写：

| 字段 | 要求 |
|---|---|
| 主张 | 一句可检验的判断：对象、方向、幅度/时间、比较对象 |
| 证据 | 2–4条最强证据，注明来源类型（公告/第三方/模型/推论）与截止日前发布日期 |
| 机制 | 从证据到利润/现金流的中间环节，落到量、价、份额、单位成本、利润率、资本开支中的具体变量 |
| 模型映射 | 该论点对应的模型变量与数值（年度、单位）；论点成立与否使估值变化多少 |
| 反证 | 最强相反证据或替代解释；可观测失效条件与观察窗口 |
| 正文落点 | 所在章节、配套图表ID |

检查：论点之间不重复；至少一张卡针对行业格局、至少一张针对公司相对竞争力（有同行比较）、至少一张直接对应估值主驱动。证据栏只有“模型预测”的论点不是论点，是假设，移入假设表。

## 4. 估值锚与价值构成

- 方法、基期年份、倍数/折现率及其依据；
- 价值构成：价值中来自显性预测期、终值或远期年份的比例。终值或远期年份（距截止日≥3年）贡献超过60%时，标记为“远期锚依赖”，正文须展示锚年份×倍数（或g×WACC）敏感性，并讨论该远期盈利的可持续性；
- 关键数字在首页的呈现方式：哪些倍数失真（亏损、微利导致PE>100倍、负净资产），首页改用N/M或换适用指标；
- 基准/压力/上行情景各自改变了哪1–2个经营变量、改变多少，对应每股价值。

## 5. 立场与统一阈值

- 立场（stance）：`cautious`/`positive`/`neutral`，与首页结论一致；风险表必须包含与立场相反的风险。
- 统一阈值：每张论点卡的失效条件、风险触发和催化验证指标使用同一组数值，写入spec的`thresholds`（如工业收入占比、毛利率警戒线），正文以`{th:key}`引用。阈值须与当前实际值比较后设定，不能把现状本身设为触发线。

## 6. 章节大纲

按“行业格局→公司竞争力→投资逻辑→盈利预测→估值与预期差→风险与催化→附录”列出每节的结论式标题（一句判断）和所用论点卡/图表ID。标题读起来连成一条完整论证；任何一节只能写成“介绍”“概况”时，回到论点卡补研究或并入相邻章节。

## 7. 证据缺口与处理

列出影响结论的缺口、尝试过的来源、处理方式（缩小主张/条件推论/情景化/保留待核验）。这一部分只在support存在；正文只体现处理后的结论边界。

## 底稿自检（写作前全部回答“是”）

1. 核心问题换成另一家公司名后是否不再成立？
2. 能否用一句话说出预期差及其来源变量？
3. 每张论点卡是否有模型之外的证据和一个可观测的失效条件？
4. 是否知道价值中有多少来自远期年份，以及首页哪些指标失真？
5. 章节标题连起来读是否是一条论证，而不是目录？
