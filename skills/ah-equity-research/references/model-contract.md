# 模型输入、映射与数字主表

## 在公司深度报告中的角色

本文件约束后台读数、计算与追溯，不是正文目录。按重要性解决影响研究结论的数值问题；技术审计、外链/缓存状态、工具权限、完整日志、模型版本与单元格映射只存support。行业格局、竞争力和经营机制须由独立研究建立，不能从模型表名、公式或检查项自动生成投资逻辑。实质影响结论的假设或不确定性用业务、预测或估值语言在正文/方法表简明交代一次，不写检查进度和“未声称”等过程自述。

## 读取顺序

1. 文件指纹：绝对路径、SHA256、修改时间、模型自身估值日/行情日。文件修改时间不代表计算完成时间。
2. 结构：工作表（包括隐藏表）、命名区域、单位、币种、列年份、情景、外链、公式和错误值。大表盘点被截断时不能声称整本已检查。
3. 语义：根据行列标签和公式依赖定位经营假设、三表、估值输出；存在多个同名“目标价”时追踪公式引用确定基准情景。
4. 公式和缓存：分别以公式模式与 data_only 模式读取。缓存为空或 Excel 错误时不能继续使用该数值；缓存非空仍需检查模型计算状态。任何重算均在副本完成，记录引擎、时间、外链处理、宏/数据表功能支持和前后差异。
5. 复核：检查已知关键输出与用户模型呈现一致。涉及宏、外部工作簿、数据表或特殊函数时，优先原生Excel重算副本；不得宣称 openpyxl 已计算公式。无法确认的缓存标为未验证，限制相关估值结论。

## 只读辅助脚本

```text
python scripts/inspect_model.py model.xlsx --output inventory.json
python scripts/inspect_model.py model.xlsx --mapping model-map.json --output mapped-inventory.json
```

输出必须为新路径。支持 .xlsx/.xlsm；不支持 .xls/.xlsb 或加密文件时，先用可信工具导出只读副本，不尝试破解。依赖 openpyxl，先检查现成Python环境；脚本不安装依赖，不联网，不刷新外链，不执行宏。

示例映射仅表示格式；以下sheet/cell不可直接套到真实模型：

```json
{
  "metadata": {"currency": "CNY", "unit": "million"},
  "required_fields": ["equity_value", "diluted_shares"],
  "fields": [
    {"id": "equity_value", "sheet": "估值", "cell": "F40", "required": true, "unit": "million", "currency": "CNY", "period": "估值日", "scenario": "base"},
    {"id": "diluted_shares", "sheet": "估值", "cell": "F41", "required": true, "unit": "million shares", "period": "估值日", "scenario": "base"}
  ]
}
```

脚本盘点不等于完成语义审计。原模型不用DCF时，不要求映射WACC或FCFF；核心字段随方法决定。映射中的metadata是人工说明，脚本不会验证单位真假，也不会自动换算。

## 统一数值主表

正文、图表、Word表格和附录统一引用该表，不能各自手抄一套数值。重要经营驱动、三表和估值细项按经济关系整理为可编辑附录；展示字段使用业务标签、期间、单位、A/E和数值，不附工作表/单元格坐标。图表下仅写“资料来源：估值模型、团队分析”；单位、预测身份和方法不放入来源行，重要假设在正文或集中方法表中表达。单元格与完整元数据保留在底稿，每条至少保存：

`metric_id, entity/security, value_raw, value_display, unit, currency, period, actual_or_estimate, scenario, source_type, source_id, workbook_sha256, sheet, cell, formula, calculation_status`

对于外部数据，保存URL/接口名、请求参数（移除密钥）、披露日、数据时点、抓取时间、页码或表格位置。对于推导结果保存输入ID、表达式、单位变换和脚本路径。空值保留null并记录原因。

## 重点核对

- 资产=负债+权益；现金流与现金变动按模型口径勾稽；仅有估值模型而没有完整三表时不强造三表。
- 收入/分部加总，合并抵销，归母利润与少数股东，基本/摊薄EPS，预测年份与财年结束日。
- EV到股权桥中的债务、现金、投资、少数股权、租赁及养老金等以具体方法和模型口径判定，禁止重复加减。
- 估值用股数与EPS加权平均股数可能不同，应解释；不能直接用流通股数作总股本。
- 港股报价可能HKD、报表可能CNY/USD；明确FX方向，例如HKD/CNY，即1 CNY可兑换多少HKD。先统一价值与股数单位，再换报价币种。
- 逐字段核查单位：工作簿金额单位是百万元，不表示股数也是百万股。目标价可能已在公式中换成HKD，先追踪公式再决定是否换汇，防止重复转换。
- A/H两类上市股份分开标识；总市值需要按类别股数×各类价格并换为共同币种，不能简单用A股价乘全部股数或只用H股股数除集团价值。
- 所有原始计算保留精度，显示时统一四舍五入。容差按最末显示位解释，不采用宽泛百分比掩盖重大差异。

## 复杂券商模板的专项检查

- 年度股数若由净利润÷全年EPS倒推，先检查全年EPS是否由季度直接相加；不能把倒推值自动称为标准时间加权平均股数。
- 年均产能/价格中的AVERAGE可能忽略空季度，分部年均之和可能不等于总量年均；先核空白含义，不能为凑平把所有空值填零。
- 主表Check=0只代表该项恒等式成立。继续比较固定资产滚动、折旧、capex、现金变动及业务数量桥，尤其检查下游是否真受产能约束。
- 估值倍数若通过硬编码回归系数或增长率映射得到，追踪样本、日期、单位和拟合依据；没有证据时只能称模型参数。折现PE不写成DCF。
- 封面常有静态价格、目标价、上涨空间与评级，逐项和公式输出核对；时点不一时不静默择取。研究日、行情日、文件修改日和模型冻结日分别记录。
- 比较Gb与GB、百万股与亿股等单位前先核公式是否已经换算。图的A/E分界从具体系列列标签识别，不能给全年和季度序列套同一个预测起点。
