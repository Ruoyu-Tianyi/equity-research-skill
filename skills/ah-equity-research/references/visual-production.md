# 从版式设计到真实页面

## 先看真实参考，再确定本稿视觉语言

优先使用用户给定范本；没有范本时选择少量公开中文券商公司深度PDF，通常2–3份足以比较。优先券商或发行人官网，可用明确标注来源的公开转载。真正打开并查看首页、双图正文、估值和财务附录的完整页面，记录报告名称、日期、原始链接及实际看到的页码；搜索摘要、PDF文字提取和截图占位符不算视觉查看。

提炼版心、阅读顺序、信息密度、图表组合、字重、表格线与页眉页脚，形成简短本稿设计决定。不要复制Logo、署名、执业信息、水印、大段文字或整页图像；用户要求某机构“风格”时，可参考其结构，不宣称自选配色属于该机构官方规范。参考报告的日期仅用于设计溯源，不因此把其中分析或数字引入本稿研究。

## 四种版式

- 首页即研究摘要。公司名、具体研究命题、日期先行；左侧窄栏放市场快照或紧凑估值参数，右侧宽栏陈述有证据的核心判断、盈利预测和风险。默认原生Word分栏为5cm / 0.7cm栏距 / 11.6cm，不用巨大布局表承载正文。条件价值的性质放在数值旁，不让超大数字与小字限制产生误导。缺少核验行情时不编造股价曲线或评级。
- 正文按同一论点组织成组图表。17.3cm版心内双图各宽8.325cm，中间用0.65cm真实空白列分隔；各半栏标题使用独立整行色带，相关两图水平对齐。不同计量单位用独立面板，不把数列挤到不可读的双轴上。标题下正文先解释问题，再看图，图后解释含义。
- 估值页把经营驱动、价值构成、现价隐含条件和情景组织在一起，完整计算细项可下沉附录。宽表/敏感性用通栏，避免一个参数一页或图后机械重复同值表。
- 附录按经营驱动、财务预测、估值细项和研究补充分组，组合关联表格与图。保留三线表和无纵线结构，表头深蓝底白字，重点财务行浅底，普通行只用极浅底纹；金额右对齐、叙述左对齐。补充完整分项或新增比较，避免重复正文同值表。来源定位和单元格索引只存support。

## 色彩与字体层级

v1.0默认设计偏好为克制蓝灰风格：navy `#24445C`、slate `#7892A5`、gold `#AE9B74`、pale `#EDF2F5`；图表标题使用 `#4C687B`（`caption_fill`）。一级章节采用紧凑深蓝底白字带；全部图、表标题把编号与标题文字放入蓝灰整行色带，白字、默认17pt行距。单图及通栏表铺满当前版心，双图各铺满自己的半栏，中间保留0.65cm无底色空白列。表头仍为深蓝底白字，重点行浅底；二级标题用深蓝字、字号与段间距区分，保留白底。标题色带随实际行数增加高度，留适量内边距，不因通栏宽度额外增高；长标题不得裁切。正文大面积保持白底，米金只用于少量标记，来源文字保留足够对比度；当前用户指定的模板与偏好优先。

默认中文为楷体（KaiTi），英文和数字为Times New Roman，覆盖标题、正文、表格、图表、目录与页眉页脚；用户可另行指定模板字体。默认中文正文10.5pt、15.5pt行距，层级由字号和字重建立，不用不同中文字体区分角色。Word的East Asia字体与ASCII/HAnsi字体分别设置，清除会覆盖指定字体的主题继承；图中的中英文混排、刻度及图例也显式应用相应字体。真实安装字体、Word实际字形与PDF导出字形须一致检查；只设置名称不足以证明已正确显示。固定行距下仍须确认字形、上标与强调数字无裁切。

色块必须与语义对应。章节带、图表标题带和表头分别采用一致的内边距规则，用深蓝与蓝灰区分层级；财务小计继续用浅底。关键财务行按标签选择；`subtotal_rows`为数据行零基索引，错一行会突出非经营项等无关字段。双图各有独立标题带与一行简短资料来源，中间留白贯穿标题和图组，不给整个图组套厚边框。仅调整标题填色时保持既有研究文字和数值不变。图表下方不附解释注、免责或口径长文；单位、期间、分母、A/E移入标签、标题或表头，重要假设在正文或方法表只交代一次。来源ID、页码、工作表/单元格及完整URL只存support。

## 工程实现

默认排版模块为 `scripts/research_editorial_layout.py`，公开类为 `EditorialReport`（`ResearchEditorialLayout`的别名）。它依赖Python、python-docx和Pillow，负责可编辑DOCX装配，不提供事实抓取、估值计算或PDF导出。执行前检查当前主题与接口是否实际落实本规范的字体、颜色、紧凑色块与纯来源行；规范同时约束独立生成的图表，不能仅调整DOCX样式。`Theme(color_blocks=False)`可用于关闭填充的用户偏好，但不应改变指定字体。研究判断、数据正确性和最终视觉验收仍由生成流程完成。

通用制图模块为 `scripts/chart_style.py`，依赖Matplotlib，不包含公司数据、固定输出目录或图号筛选。`configure()`默认查找系统已安装的KaiTi与Times New Roman；也可传入`kaiti_path`、`times_path`和可选的`times_variant_paths`（粗体/斜体文件）。脚本核对实际字体家族，缺少字体或路径指向其他字体时直接报错，不静默回退。字体文件由使用者所在环境提供，不随公开skill打包。

将scripts目录加入Python搜索路径后，以下合成数据仅用于演示接口：

```python
from chart_style import configure, figure, style, legend, save, PALETTE

configure()  # 或传入本机的kaiti_path、times_path
fig, ax = figure(wide=False, height=2.6)
ax.bar(["2024A", "2025A", "2026E"], [100, 120, 135],
       color=PALETTE[0], label="收入示例")
style(ax, "亿元")
legend(ax, ncol=1)
audit = save(fig, "outputs/figures/example_revenue",
             layout={"top": .75, "bottom": .20, "left": .18, "right": .97})
```

`save()`接收不含扩展名的输出路径，默认导出320DPI PNG、轮廓化SVG与`.audit.json`；导出前统一中英字体，检查画布外文字，导出后核对SVG字形字体及缺字警告。默认`strict=True`，字体或越界检查失败时保留预览与失败记录并抛错，不能将脚本结束或生成图片当作通过。记录绑定PNG/SVG哈希；不预设“数据未改变”。检查仅覆盖字体与画布边界，不能替代数据核对、标签重叠检查和最终版面目检。

Windows且已安装桌面Microsoft Word时，可使用通用 `scripts/export_word.ps1`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/export_word.ps1 -DocxPath "outputs/report.docx" -PdfPath "outputs/report.pdf"
```

上述执行策略参数仅作用于本次PowerShell子进程，不更改系统配置。导出器预检KaiTi和Times New Roman，确认新建了独立Word进程后隐藏运行；更新本地目录、页码及引用字段，在各正文/页眉页脚文本区域应用指定字体，重新分页，保存传入DOCX并导出PDF。它不刷新外部链接或数据库字段，不改Word全局设置，仅关闭自己打开的文档与创建的实例；若新实例无法确认独立，停止操作而不退出已有Word。传入本次生成稿，不能把原始资料当作输出稿。返回页数和文件哈希仅证明导出完成，仍需渲染PDF、检查实际字体、目录页码与全稿版面。

将skill的scripts目录加入当前Python搜索路径后，可使用以下接口；示例中的内容须由本次研究填充，不是默认研究结论：

```python
from research_editorial_layout import EditorialReport

r = EditorialReport(company="公司名", ticker="证券代码", date="研究截止日")
r.cover(
    params={"title": "具体研究命题", "facts": [("行业", "已核验行业")],
            "valuation": "估值结论、方法与适用条件", "risks": "关键风险"},
    theses=[{"lead": "核心判断。", "text": "事实、机制与投资含义。"}],
    forecast={"headers": ["指标", "年度A", "年度E"],
              "rows": [["预测指标", "实际值", "预测值"]],
              "title": "主要预测", "source": "资料来源：估值模型、团队分析"},
)
r.toc()  # 原生TOC域；须在文档引擎中更新
r.heading("行业格局", level=1, number=1, page_break=True)  # 首章段前分页
r.subheading("支持投资逻辑的行业变化")
r.paragraph("证据及其经济含义；重要假设在此或集中方法表交代。", bold_lead="明确判断。")
r.table(["指标", "期间A", "期间E"], [["指标名", "实际值", "预测值"]],
        title="分析表（单位、期间）", source="资料来源：公司公告、团队分析", widths=[6.3, 5.5, 5.5])
r.figure("全宽图.png", caption="原创分析的结论式标题", source="资料来源：团队分析")
r.pair(["左图.png", "右图.png"], ["左图标题", "右图标题"],
       ["资料来源：公司公告", "资料来源：估值模型、团队分析"])
r.save("报告.docx")
```

示例来源须按实际数据替换；原创分析的来源写法不适用于外部事实图。`source`传入整理好的简短真实来源；渲染器完整保留该文本，不靠截断来源字符串清除说明。单位、A/E和重要假设在相应标签、标题、正文或方法表中组织，不拼接到`source`。`table`的`title`/`caption`、`widths`/`widths_cm`分别为别名，每组只传一个。`figure`/`pair`使用可读的本地PNG等栅格文件；SVG另存为制图档案，不能假定该模块直接嵌入SVG。`save`只写DOCX；字段刷新、PDF导出和页面渲染另用实际可用的文档工具完成。

`pair`将标题、图像和来源分别放在共享的三行区域中，左右两图间为独立0.65cm空白列。长短标题共用标题行高度，图像从同一水平位置开始，来源也在统一行区域内；这减少由单侧换行造成的错位。标题长度、图像比例与分页仍须在实际导出的页面上检查，结构对齐不等于最终观感已通过。

若本次用户偏好少填充主题，使用`from research_editorial_layout import EditorialReport, Theme`，再传入`EditorialReport(..., theme=Theme(color_blocks=False))`。这只改变色块方案，不暗中替换研究内容或字体组合。

渲染器自动添加图、表编号，传入的`caption`/`title`只写标题内容，不再手写“图N”“表N”；引用采用最终自动编号。目录后若需起正文页，使用首章`heading(..., page_break=True)`（即段落`page_break_before`），避免另加一个分页段把目录尾部挤出空白页。正文各章仍默认自然连排。

目录样式使用Word内置的`toc 1`、`toc 2`，不存在时以`builtin=True`创建；不要另建大小写不同的自定义`TOC 1`/`TOC 2`代替。Word更新目录可能将冲突样式改名为`TOC11`等，造成一级与二级字体/颜色层级丢失。新版`toc()`已配置内置样式，报告装配脚本不再重复创建自定义目录样式；导出后仍检查实际目录层级与页码。

检查PDF实际字体，不能只检查DOCX的默认字体声明。Word更新目录后可能生成采用主题字体的空格或字段字符；若发生回退，在字段更新后分别设置各StoryRange的NameFarEast为楷体、NameAscii/NameOther/NameBi为Times New Roman，再重新分页、保存并导出。只调整字体名称，保留字号、字重、颜色与上标等格式。估值公式中的幂次用原生上标，不以文字插入符号代替。

生成器按本公司经过核实的内容与图表清单装配，不加载上一份样稿的公司数据、证券代码或模型坐标。保持正文与Word表格可编辑，图表数据和来源另存。核实实际提供了哪些功能后，再决定字段更新与PDF导出路径。

正文与多数附录连续流式排版；首页之后、财务附录起始或确有内容需要才插入硬分页。章节标题不等于新页。最终目录及交叉页码由实际导出的PDF或正确更新的Word字段回填，再次导出复查，不能套用设计阶段页码。跨页位置不稳定时优先使用图表号或附录编号。

Word图片段落用自动/单倍行距，不能继承正文的固定行距，否则图片可能被裁至一行。新版`figure`/`pair`已处理；若在首页窄栏直接调用`add_picture`，必须为图片所在段落单独设置`paragraph_format.line_spacing = 1`。图注与图片保持同页，图片与资料来源同页。短表尽量整表同页；长表保证标题和前三行相连，续页重复表头。页眉页脚的Tab需清除继承的居中制表位，实际核对公司名与页码是否右对齐。

半栏图按最终约8–8.5cm宽重绘，源图约3.4–3.6英寸宽，常用8.5–10pt字体；不要把更宽图缩入半栏后仍按源字号宣称可读。半栏内再次切两个窄面板时应改通栏。不同单位/季度用独立面板并明确标注，不能共享轴造成同口径错觉。清除无意义底色，用A/E、虚线与轻分界表达预测期；柱图系列色跨期保持一致。300DPI以上PNG与SVG同时保存。

## 视觉验收必须独立于内容验收

先做首页、双图正文、估值和附录的代表页，实际查看后再推广全稿。最终PDF需渲染全部页并逐页以可读尺寸打开；联系表仅用来发现漏页/重复页，不能替代逐页查看。除溢出、断表、乱码外，还须判断：

1. 五秒内能否看清公司、研究命题、核心判断、估值性质。
2. 图例颜色是否与图中序列对应，预测期变色是否有解释。
3. 是否仍存在逐页相同结构、一页一图、图后重复表和大段流程说明。
4. 是否反复出现大段底部空白；若由硬分页或内容碎片化造成，合并相关内容。完整图块移到次页、章节结束等自然分页可保留合理空白，不机械规定填满比例。
5. 半栏图最终字号、单位和图例是否可读；图标题与左右图是否对应。
6. 两栏顶端是否齐平，大数字有无压住标签；字重、行距、表格底色是否全稿一致。
7. 深蓝色带白字是否清晰且有内边距，二级标题的字号、字重和间距是否与一级标题形成明显层级；颜色填充是否帮助定位而非把正文切成满页卡片。
8. 全部中文是否为KaiTi、全部英文数字是否为Times New Roman，尤其混合图题、图例、坐标、表格与目录；财务高亮是否落在正确标签，浅底纹在PDF和打印尺度下是否仍可辨识。
9. 所有图、表标题是否为蓝灰整行色带，编号与标题是否均为白字；单图通栏、双图各半栏的宽度是否正确，中间0.65cm是否保持真实白色间隔。17pt行距下有无裁字，长标题换行后两侧是否对齐；是否存在无内容空高。图表下是否只有简短真实资料来源，单位、期间、分母与预测身份是否已在图内或表头中表达，重要假设是否在正文或方法表集中交代，底稿能否追溯原始来源。

不能用“没有溢出”“共多少页/图”替代专业观感判断。用户否定观感时，重新设计代表页面和整体编排；用户否定研究深度时，回到研究和证据阶段，不能用换色、加图或加页数解决。

记录实际看过的页、具体缺陷、修正与未验证范围，并绑定当前DOCX/PDF文件哈希。调整排版、图表或目录后重渲染受影响页；改动引起全稿重排时重查全部新页。可并行分段独立审阅，但必须覆盖最终版本的所有页面。
