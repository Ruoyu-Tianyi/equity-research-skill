# 中文Word/PDF与图表设计规范

## 页面与层级

默认A4纵向，左右页边距18–20mm，上下18mm；横向页只用于确实需要的宽附录表，用分节符保持页码连续。默认全部中文使用楷体（KaiTi），全部英文与数字使用Times New Roman，包含正文、标题、目录、表格、图例、坐标轴、标签、来源及页眉页脚。中文标点随中文字体，拉丁字母和阿拉伯数字随西文字体；中英混合文本不能整段套用楷体而使英文和数字也变为楷体。先核实字体可用；缺失时解决字体条件并披露未满足部分，不静默改用其他字体。字号以最终A4打印尺寸为准，层级依靠字号、字重、颜色和留白建立。

当前蓝灰调色板：深蓝 `#24445C`（navy）、灰蓝 `#7892A5`（slate）、米金 `#AE9B74`（gold）、浅底 `#EDF2F5`（pale），图表标题另用蓝灰 `#4C687B`，正文保留高对比深灰。一级标题采用紧凑深蓝底白字带；全部图、表标题将编号与标题文字共同放入整行蓝灰色带，文字统一白色。表格列头使用浅蓝灰 `#E8EFF4` 底、深蓝 `#24445C` 字，避免紧接标题再出现一层深色条。二级标题以深蓝字和细线区分，保留白底。关键财务行用浅底，普通行白底或极浅底纹；米金只作少量强调。标题色带按实际文字行数和适量内边距确定高度，默认17pt行距，不给色带增加无内容空高。主体保持白底，风险/负值同时使用文字或符号。此为默认设计，不宣称来自某券商官方规范；后续指定模板优先。

首页信息密集但有清晰阅读顺序：公司+代码/交易所→研究命题与日期→核心判断及依据→财务/估值摘要→可用行情与风险。摘要回答行业变化、公司优势、兑现路径和定价，不以“发现多少模型问题”开篇。估值侧栏优先紧凑参数表，条件价值明确标性质；无核验行情不填装饰曲线。非用户要求不使用空旷杂志封面。页眉为公司简称/报告类别，页脚为页码及简短用途信息；不捏造机构品牌。

章节标题14–16pt，小节11–12pt，正文约10.5pt；同一字体体系内用字号、字重、间距和深蓝字建立层级。一级标题色带保留适量上下内边距，但不把标题扩成独立大卡片。段首判断可用深蓝加粗，正文保持常规字重；不用假斜体或连续大段加粗。正文单栏为主，同主题图采用两列比较；首页可用原生Word分栏组织研究逻辑与关键指标。标题与下段同页，避免孤行。少量数字放大须相应提高段落行高，不能套用正文固定行距。表头重复、金额列右对齐、单位放表头、负数格式统一。避免让一行表格跨页；长表可跨页但重复表头。

紧凑正文起点为10.5pt、15.5pt行距、段后5pt，最终以楷体实际字形的可读性与行高为准；段首判断只改变字重和深蓝色，不把整段变为强调文字。自然段按研究问题划分，不由渲染器截断。正文、表格文字、图内文字与资料来源都应位于所属标题/章节色带的左右边界内；正文左右默认各内缩1.2mm，标题带自身铺满所属版心。清除段落继承的负缩进、悬挂/首行外凸及表格偏移，禁用行末标点悬挂并保留正常中文禁则。按最终PDF检查实际字符含行末标点，不能只检查段落框或标称宽度。

表格保留克制三线结构，不加纵线和逐格网格；顶线与列头下线用细浅线，底线适度强调。标题带维持 `#4C687B` 白字，列头改为 `#E8EFF4` 浅蓝灰底与 `#24445C` 深字，表体白底与极浅底纹，关键行采用浅底和深蓝字。关键行由经济含义确定，例如收入、营业利润、归母利润、总资产、总负债和总权益，不按行号随意强调。`subtotal_rows`为数据行的零基索引，传参前核实标签。表内默认8.8pt、12.4pt行距，首列约25%–30%；完整数值右对齐，含年份或数字的叙述句仍左对齐。七条数据以内的短表默认尽量同页，长表按行自然跨页并重复浅色列头。

默认通栏色带17.3cm，双图每侧色带8.325cm、间隔0.65cm，各有独立标题和来源。单图及通栏表的标题色带铺满当前版心；双图中间为无底色的真实空白列，不能用同色底加空格模拟留白，也不能把两幅图连成一条整宽色带。两侧标题色带顶端对齐，长标题正常换行并保持同组高度协调，不能截字或缩小字号硬塞。完整图画布在色带内左右各留1.2mm，默认可用宽度上限为通栏17.06cm、半栏8.085cm；画布包含图例、轴和标签，并非只指坐标绘图区。

优先按目标宽度重绘，缩减过多外缘空白并放大图内有效内容；保留单位、期间、A/E及必要标签空间，不裁切已有位图来凑宽度。不再用固定5.5cm/8.5cm图高上限缩小整图。高度由图形比例和可读性决定，必要时改通栏、拆图或自然续页；不拉伸图像、不缩小字体或删数据来维持页数。仅做版式更新时保留既有研究文字与数据，用户指定模板优先。

用真实Word标题样式生成可更新目录、图表编号、页码和交叉引用，导出前更新字段。若工具无法刷新目录字段，不交付带错误页码的“已完成目录”；改用准确静态目录并记录限制。

## 图表规划

先建图表清单：ID / 主张与比较问题 / 图形 / 数据ID、单位和期间 / 来源定位 / 放置章节 / half或wide / 状态。独立行业与公司证据应支持主要论点，不能让全稿图表都只是重画用户预测。以下是选择库，不要求每个公司全做：

| 模块 | 推荐图表 | 对读者的问题 |
|---|---|---|
| 行业格局 | 市场规模、集中度/份额、供需/价格序列、分终端对比 | 利润池如何变化，供需与定价机制是什么 |
| 公司竞争力 | 业务结构、产品/客户结构、同行可比指标、成本/效率、产业链位置 | 为什么由本公司获取收益，优势能否维持 |
| 财务与预测 | 收入及增长、分部量价、利润率、利润桥、费用率 | 增长和利润率如何实现 |
| 盈利质量 | 净利润vs经营现金流、营运资本周转、capex/折旧 | 盈利是否兑现为现金 |
| 回报与风险 | ROIC与WACC、ROE分解、债务期限/现金覆盖 | 增长是否创造价值，资金是否够用 |
| 核心估值 | 估值方法区间图、EV到股权价值瀑布、DCF现值构成 | 价值如何从模型得出 |
| 不确定性 | 二维敏感性热力图、情景价值图、单因素敏感性图 | 哪些变量最影响价值 |
| 定价对照 | 同行倍数表/散点、历史估值、市场隐含预期 | 相对便宜还是贵，为什么 |
| 市场信息 | 股价与基准归一化走势、事件标记 | 定价变化与催化剂对应什么 |

深度报告估值部分应覆盖适用的价值桥、核心预测、可比或独立交叉检验、情景/敏感性及现价对照。没有数据的图不占空位，缺口影响结论时说明。

## 制图细节

- 用matplotlib、R/ggplot或可复现制图工具从统一数值主表生成，模型数组/CSV与图一同保存。不得用AI画数值图，不用网页截图替代可复算图表。
- 历史与预测用A/E、轻分界、线型或明确填充区分；同一业务/情景颜色全文固定，柱图不要因预测期变浅而与另一系列串色。机构预测区间直接画区间并标发布时点，不取中点制造精度，也不称为统计置信区间。
- 每图保留图号、结论式标题、坐标单位、时间区间和图例；A/E、同比/环比、收入/数量口径等通过图内标签、标题或表头表达。正文解释相关图组支持的论点和经营含义，避免逐图重复数字或附上提醒段。
- 数量/金额柱状图从0起；折线如截轴要清楚显示，不能通过截轴夸大变化。避免无必要双轴；不同单位、季度或分母优先独立面板并明确标注。收入、台数、bit与产能不可因都能算同比就混成同一含义。多系列过多时考虑小倍图。
- 价格与基准比较采用同日期、同回报口径、同起点归一化；不把价格指数与含分红总回报混比。停牌/节假日保留真实日期处理逻辑。
- 热力图展示实际单元格数值，标出基准格、单位和现价参考；无效组合显示N/A。色域不能把所有情景都画成“积极”。
- 估值区间图统一成每股同币种并标现价线；瀑布图区分流量增减与小计/总计，检查加总。
- 导出SVG/PDF用于矢量存档，Word按支持情况嵌入SVG或300DPI以上PNG。按实际插入宽度制图，正文图的图例、轴标题/刻度、单位和数据标签统一以最终8.75pt为起点，封面小图8.5pt，建议8.5–9pt；不能把大图缩小后仍按源文件字号宣称可读。优先调整标签密度、图例位置与绘图区边距，减少无效空白，而不是把图塞进固定高度。
- 图表中文使用KaiTi，英文与数字使用Times New Roman；坐标刻度、图例、注释和混合标签同样遵守。显式处理混合字体与导出嵌入，不能只改Word文字而保留旧图中的字体。
- 图表下方只放一行简短资料来源，不附解释注、免责、单位、期间、预测身份或口径说明。上述必要信息移入图内标签、表头或标题；无法简化为标签的重要假设在相关正文或集中方法表交代一次。

来源用语按真实材料选择：原创分析为“资料来源：团队分析”；用户模型为“资料来源：估值模型、团队分析”；公开事实为“资料来源：公司公告”或“资料来源：IDC”等真实简名；基于公开事实加工可写“资料来源：公司公告、团队分析”。混合来源保留确实使用的材料名称。“团队分析”不用于掩盖未知来源、未经核验的历史事实或虚构数据。来源ID、PDF页码、Excel工作表/单元格、完整URL留在support的来源账本与模型映射。

## 装配和交付

正文与表格保持可编辑，不把整页贴图进Word。图表与文字共同完成一个判断：正文解释问题、机制与公司含义，不逐项复述数字，也不在每幅图之后追加防御性说明。连续排版随内容组织图组，不设每页图数硬指标。附录按经营驱动、财务预测、估值细项及研究补充分组，收录对判断有价值但正文未完整展开的数据；已经完整展示的图表以交叉引用代替重复。重要方法用一张紧凑表集中交代，技术过程只放support。宽表使用通栏、横向节或合理拆表，不能靠极小字体解决。

报告至少具备：可读首页、清晰目录、层级统一的正文、可核对的估值章节、完整附录、可追踪来源。按用户指定模板优先调整，样例中的颜色与页数可以改变。

先确认可用的DOCX转PDF引擎。Windows环境没有bundled LibreOffice时，若已安装Microsoft Word，可用独立后台实例只打开本次生成稿、更新字段、导出PDF，最后仅关闭该文档及自己创建的实例；不改用户全局设置或打开原始估值模型。再用可用的PDF渲染工具生成所有页面图。明确记录实际渲染路径，不声称运行了未使用的渲染器。

检查Word模板隐含样式：清除标题继承的装饰边框、斜体、主题色和外凸缩进；数值列右对齐，叙述单元格左对齐，表后保留适量间距。正文及表格不得越过所属色带的左右边界。最终PDF同时检查字体家族、实际字号、图画布边界和有效内容占用空间；静态目录页码与实际分页逐项一致。

交付DOCX/PDF主稿和一个support目录：figures、chart-data、source-register、model-map、必要补算与quality-review。原始API返回如含授权限制或敏感信息，仅在允许的内部存档，不默认打包对外发送。
