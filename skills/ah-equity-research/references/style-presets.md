# 可选风格与附录模式

用于用户选择报告风格，或要求附录更简洁时。默认保留已认可的`blue_gray`正文；用户未提出换风格，不随机替换或逐页轮换。风格只调整色彩、章节处理及间距，不改变研究主线、数据、估值方法、中文楷体与英文数字Times New Roman。

## 五套方案

| 名称 | 中文名称 | 正文章节处理 | 图表与表格特点 |
|---|---|---|---|
| `blue_gray` | 克制蓝灰，默认 | 深蓝实心带、白字 | 蓝灰图表标题带，灰蓝/米金系列，浅蓝灰列头；保留既有正文设计 |
| `forest_sage` | 森林绿与鼠尾草 | 浅色底、深绿字，细线 | 深绿图表标题带，鼠尾草辅助色与浅绿灰列头；正文行距略舒展 |
| `burgundy_slate` | 酒红与石板灰 | 酒红实心带、白字 | 酒红图表标题带，石板灰系列与暖灰列头；正文紧凑 |
| `ink_gold` | 墨色与暖金 | 墨色字、暖金细线，白底 | 墨灰图表标题带，灰/暖金系列与浅暖灰列头；正文间距略舒展 |
| `graphite_teal` | 石墨与青绿 | 石墨色字、细线，白底 | 石墨青图表标题带，青绿系列与浅灰青列头；段后略紧凑 |

五套方案的正文图表标题默认均为实心带白字；表中的浅底/细线差异主要指章标题。附录另按下述简化层级处理。配色与排版字段集中于`scripts/design_presets.py`，文档与制图使用同一个名称；这些方案是通用自定义设计，不代表任何券商的品牌模板。

## 选择与调用

优先采用用户指定的方案或模板。用户只要求改善附录时，仅启用附录模式，保留正文主题。需要比较风格时，可用同一组内容制作少量代表页；正式稿选择一套，不把不同方案混排为样式合集。

```python
from research_editorial_layout import EditorialReport, Theme
import chart_style as charts

style_name = "blue_gray"  # 按用户选择替换
theme = Theme.preset(style_name)
charts.configure(theme=style_name)
r = EditorialReport(company="公司名", ticker="证券代码", date="研究截止日",
                    theme=theme)

# 正文、图表和原生表格按本次已核实的研究内容装配。
r.heading("经营驱动与盈利预测", level=1)
r.begin_appendix("附录一 经营与财务预测", number=7)
# 此后的标题、段落、表格和图表标题使用附录区域样式。
r.end_appendix()  # 后面还有正文式内容时显式退出
```

`Theme.preset(name, **overrides)`先载入方案，再应用调用方覆盖；字段只作用于该Theme实例。`charts.configure(theme=...)`接收方案名称字符串，不接收Theme对象或字典，也不读取报告当前区域；须在创建新图前调用。用`charts.PALETTE`或默认色轮取序列颜色，避免图表内硬编码旧配色。自定义Word颜色覆盖不会自动传到制图；确需覆盖图表序列色时，可向`configure`传入四个`#RRGGBB`颜色的`palette`，并重新检查图例、标签对比度和系列语义。已有Figure与已导出的PNG/SVG不会因切换主题自动变色，需要从原始数据重绘。

## 自定义研究名称

构造报告时可传入`research_brand="示例策略研究"`，首页顶部色带与页眉左侧统一显示该名称；公司名、证券代码和`report_type`报告类型保持各自含义，不用品牌名称替代。

```python
r = EditorialReport(company="公司名", ticker="证券代码", date="研究截止日",
                    theme=Theme.preset("blue_gray"), research_brand="示例策略研究")
```

省略该参数或传入`None`时，读取当前skill根目录的`config.local.json`中`research_brand`；无配置则沿用`report_type`。显式字符串覆盖本机默认；显式空字符串`""`表示本次不使用默认品牌，直接回退`report_type`，不会再读取本机配置。例如，本机文件可写：

```json
{"research_brand": "示例策略研究"}
```

本机配置供个人环境使用，已列入Git忽略规则，公共发布包不包含该文件。分享skill时保留通用说明，不复制个人默认名称；最终报告中的研究名称按本次用户要求检查，不据此声称发布资质。

## 附录简化层级

默认附录降低装饰强度，同时保留数据密度与可读性：

- 章标题：所选主题的浅底、深字和细底线；二级标题用深字、字号与间距区分，减少金色竖线装饰。
- 图表标题：浅带深字及细线，保留通栏或双半栏结构和0.65cm中缝；默认标题8.8pt、15.5pt行距。
- 表格：白底深字列头，极轻斑马纹，关键行轻填充；数值字号、单位和重复表头规则不降低。
- 间距：默认段后4pt，缩减标题、表后和来源周围的多余间距；不压缩数字、图字或图片来凑页数。

`begin_appendix(title, number=None, page_break=True)`显式进入附录模式并添加一级标题，默认从新页开始；后续附录分组可以传`page_break=False`自然连排。`heading(..., level=1)`的标题以“附录”或“Appendix”开头时也会进入模式，显式调用更可靠。普通一级标题不会自动退出；返回正文式内容前调用`end_appendix()`。

`content_theme`属性返回当前区域的有效主题。`Theme.appendix()`从所选主题派生附录参数，保留原主题，区域切换不追溯修改已生成正文。图表的数据系列配色仍沿用全稿所选方案，不因为进入附录就改变同一业务的颜色含义；附录简化主要作用于文档标题、表格及间距。

若用户要求少填充，可用`Theme.preset(style_name, color_blocks=False)`：正文和附录均不填底色，附录仍保留深字、细线与较紧的间距。不要把“不填色”误解为关闭附录区域，也不强制所有用户采用默认浅底效果。

## 内容与验收边界

附录的重要经营驱动、财务预测、估值细项及研究补充分组保持完整；简化样式不是删资料。换主题和进入附录后，检查数字、字段、单位、A/E、公式与来源未改变，并重新检查目录和自然分页。章节层级、颜色对比、图例语义、最终图字、通栏/双栏边界及长表续页均以实际PDF为准。脚本支持主题和区域切换，不等于已完成专业观感验收。
