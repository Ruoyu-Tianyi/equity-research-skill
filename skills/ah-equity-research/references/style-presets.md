# 可选风格与附录模式

用于用户选择报告风格，或要求附录更简洁时。默认使用`institutional`机构研究风格（v2.2起）；此前的`blue_gray`等编辑色带风格保留可选；用户未提出换风格，不随机替换或逐页轮换。风格只调整色彩、章节处理及间距，不改变研究主线、数据、估值方法、中文楷体与英文数字Times New Roman。

## 六套方案

| 名称 | 中文名称 | 正文章节处理 | 图表与表格特点 |
|---|---|---|---|
| `institutional` | 机构研究，默认 | 海军蓝粗体+下划线，无底色 | Exhibit式图题（顶线、无底色），三线表、预测列浅灰底，海军蓝/钢蓝/灰/琥珀 |
| `blue_gray` | 克制蓝灰（v2.1前默认） | 深蓝实心带、白字 | 蓝灰图表标题带，灰蓝/米金系列，浅蓝灰列头；保留既有正文设计 |
| `forest_sage` | 森林绿与鼠尾草 | 浅色底、深绿字，细线 | 深绿图表标题带，鼠尾草辅助色与浅绿灰列头；正文行距略舒展 |
| `burgundy_slate` | 酒红与石板灰 | 酒红实心带、白字 | 酒红图表标题带，石板灰系列与暖灰列头；正文紧凑 |
| `ink_gold` | 墨色与暖金 | 墨色字、暖金细线，白底 | 墨灰图表标题带，灰/暖金系列与浅暖灰列头；正文间距略舒展 |
| `graphite_teal` | 石墨与青绿 | 石墨色字、细线，白底 | 石墨青图表标题带，青绿系列与浅灰青列头；段后略紧凑 |

除`institutional`外，其余五套方案的正文图表标题为实心带白字；表中的浅底/细线差异主要指章标题。附录另按下述简化层级处理。配色与排版字段集中于`scripts/design_presets.py`，文档与制图使用同一个名称；这些方案是通用自定义设计，不代表任何券商的品牌模板。

## 默认：机构研究（institutional）

参照国际投行（bulge-bracket）公司研究的通行版式惯例，不复制任何机构的标识、版面或文字：

- **色彩**：单一主色深海军蓝 `#13294B`；辅助钢蓝 `#5C88B5`、中性灰 `#A6A6A6`；琥珀 `#C99A2E` 只用于现价线等需要读者第一眼看到的标记。正文墨色 `#1E2328`，次要文字 `#5E6573`。不使用大面积色块。
- **层级靠线与留白**：封面顶部为研究名称+日期，下方1.5pt海军蓝线；章标题为14pt海军蓝粗体加1.25pt下划线；二级标题11.5pt粗体，无竖条装饰；封面侧栏小标题为粗体加细下划线。
- **图表标题**：“图 1：标题（单位）”海军蓝粗体，下方细线（中文研报通行格式）；双图各自标题、中间真实留白；目录后自动生成“图表目录”。图下一行“资料来源：……”。
- **表格**：三线表——表头上1pt海军蓝线、下0.5pt线，表尾1pt线；无表头底色、无斑马纹；小计行粗体加细顶线；**预测列（如2026E）整列浅灰底** `#F3F5F7`，历史与预测一眼可分。数字列整列右对齐。
- **图形**：坐标轴中性灰，仅保留水平网格；预测期用竖向虚线加“预测”小字标识，不铺底色；估值区间条用浅钢蓝，现价线琥珀虚线；敏感性热力图低于现价为灰阶、高于现价为蓝阶，基准格加框。
- **品牌与中文研报元素**（v2.3）：封面顶部品牌条——logo、中文研究名称、英文名（字距加宽）、右侧海军蓝“公司深度研究”标签与日期，下方海军蓝粗线配金色细线；章节编号为金色粗体数字（不用底纹方块，以免Word目录遮字）；图表编号为海军蓝白字小标签、标题粗体、下方细线；封面侧栏小标题为浅灰底加左侧海军蓝色条；二级标题带左侧色条；页眉左侧为小logo与研究名称。logo等品牌资源放在工作区`brand/`，在`config.local.json`登记`research_brand_en`、`brand_logo`、`brand_logo_header`，不进入公共发布包；未配置时版式照常，仅不显示logo。
- **中文卖方研报版式**（v2.5，参照国盛、财信、国联民生等公开报告的通行结构，不使用其标识与文字）：
  - 封面：品牌条下为双色通栏——左侧钢蓝“公司深度研究”、右侧海军蓝“公司（代码）”，与下方左右两栏对齐；左栏依次为公司资料、股价表现、（可选）涨跌幅比较、估值摘要、研究员、相关研究；右栏“投资要点”各段以“■”起头、首句加粗，随后“风险提示：”一段与主要财务指标表。
  - 正文：一级标题“1 类别：判断”（金色数字），二级标题自动编号“1.1”“1.2”；段落首行缩进两字、段首判断加粗；图表“图 1：……”并附“资料来源：机构，机构”。
  - 文末：附录收录经营假设、财务报表与估值附表，之后为重要声明。
- **页面**：页眉为研究名称与公司代码（细线下划），页脚为公司、日期与“请阅读末页重要声明”及页码（细线上划）；正文末尾附“重要声明”小字段落（spec可用`disclaimer_text`替换或`disclaimer: false`关闭）。

## 选择与调用

优先采用用户指定的方案或模板。用户只要求改善附录时，仅启用附录模式，保留正文主题。需要比较风格时，可用同一组内容制作少量代表页；正式稿选择一套，不把不同方案混排为样式合集。

```python
from research_editorial_layout import EditorialReport, Theme
import chart_style as charts

style_name = "institutional"  # 按用户选择替换
theme = Theme.preset(style_name)
charts.configure(theme=style_name)
r = EditorialReport(company="公司名", ticker="证券代码", date="研究截止日",
                    theme=theme)

# 正文、图表和原生表格按本次已核实的研究内容装配。
r.heading("经营驱动与盈利预测", level=1)
r.begin_appendix("附录一 经营与财务预测", number=7)
# 此后的标题、段落、表格和图表标题使用附录区域样式。
r.end_appendix()  # 后面还有正文式内容时显式退出
```

`Theme.preset(name, **overrides)`先载入方案，再应用调用方覆盖；字段只作用于该Theme实例。`charts.configure(theme=...)`接收方案名称字符串，不接收Theme对象或字典，也不读取报告当前区域；须在创建新图前调用。用`charts.PALETTE`或默认色轮取序列颜色，避免图表内硬编码旧配色。自定义Word颜色覆盖不会自动传到制图；确需覆盖图表序列色时，可向`configure`传入四个`#RRGGBB`颜色的`palette`，并重新检查图例、标签对比度和系列语义。已有Figure与已导出的PNG/SVG不会因切换主题自动变色，需要从原始数据重绘。

## 版式：图文分栏（左图右文）

除默认的通栏版式外，可在spec设置`"layout": {"mode": "figures_left"}`，正文各小节的图表全部放在左栏、分析文字放在右栏，适合图表较多的深度报告：

- 以二、三级标题为界分组：同一小节内的图（含双图，拆成上下两张）与估值足球场图进入左栏，段落进入右栏；没有图的小节保持通栏。
- 左栏默认8.33厘米，正好容纳半宽图表，图表按原尺寸绘制、字号不缩小；间距0.5厘米，右栏约8.2厘米。可用`left_cm`、`gap_cm`调整，右栏不得窄于6厘米。
- 宽表格（盈利预测、风险、估值方法表等）放在该小节的分栏之后通栏显示；窄表可写`"column": "left"`放入左栏。
- 首页、附录与文末财务报表整页不分栏。
- 分栏会增加页数（宇树测试由13页增至15页）；图表少的报告用通栏更紧凑。

## 自定义研究名称

构造报告时可传入`research_brand="示例策略研究"`，首页顶部色带与页眉左侧统一显示该名称；公司名、证券代码和`report_type`报告类型保持各自含义，不用品牌名称替代。

```python
r = EditorialReport(company="公司名", ticker="证券代码", date="研究截止日",
                    theme=Theme.preset("institutional"), research_brand="示例策略研究")
```

省略该参数或传入`None`时，读取当前skill根目录的`config.local.json`中`research_brand`；无配置则沿用`report_type`。显式字符串覆盖本机默认；显式空字符串`""`表示本次不使用默认品牌，直接回退`report_type`，不会再读取本机配置。例如，本机文件可写：

```json
{"research_brand": "示例策略研究"}
```

本机配置供个人环境使用，已列入Git忽略规则，公共发布包不包含该文件。分享skill时保留通用说明，不复制个人默认名称；最终报告中的研究名称按本次用户要求检查，不据此声称发布资质。

## 附录简化层级

默认附录降低装饰强度，同时保留数据密度与可读性：

- 章标题：所选主题的浅底、深字和细底线；二级标题用深字、字号与间距区分，减少金色竖线装饰。
- 图表标题：浅带深字及细线，保留通栏或双半栏结构和0.65cm中缝；默认标题8.8pt、15.5pt行距。
- 表格：白底深字列头，极轻斑马纹，关键行轻填充；数值字号、单位和重复表头规则不降低。
- 间距：默认段后4pt，缩减标题、表后和来源周围的多余间距；不压缩数字、图字或图片来凑页数。

`begin_appendix(title, number=None, page_break=True)`显式进入附录模式并添加一级标题，默认从新页开始；后续附录分组可以传`page_break=False`自然连排。`heading(..., level=1)`的标题以“附录”或“Appendix”开头时也会进入模式，显式调用更可靠。普通一级标题不会自动退出；返回正文式内容前调用`end_appendix()`。

`content_theme`属性返回当前区域的有效主题。`Theme.appendix()`从所选主题派生附录参数，保留原主题，区域切换不追溯修改已生成正文。图表的数据系列配色仍沿用全稿所选方案，不因为进入附录就改变同一业务的颜色含义；附录简化主要作用于文档标题、表格及间距。

若用户要求少填充，可用`Theme.preset(style_name, color_blocks=False)`：正文和附录均不填底色，附录仍保留深字、细线与较紧的间距。不要把“不填色”误解为关闭附录区域，也不强制所有用户采用默认浅底效果。

## 内容与验收边界

附录的重要经营驱动、财务预测、估值细项及研究补充分组保持完整；简化样式不是删资料。换主题和进入附录后，检查数字、字段、单位、A/E、公式与来源未改变，并重新检查目录和自然分页。章节层级、颜色对比、图例语义、最终图字、通栏/双栏边界及长表续页均以实际PDF为准。脚本支持主题和区域切换，不等于已完成专业观感验收。
