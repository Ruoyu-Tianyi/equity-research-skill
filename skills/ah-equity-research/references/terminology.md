# 专业用语与格式规范

成稿面向机构读者，用卖方研报的标准表述。写作与重写时按本文件逐项检查；`build_report.py`会对其中可机器判断的部分报错或警告。

## 一、叙述主体与口吻

- 研究判断与预测以研究机构为主体：“我们认为”“我们预计”“我们的盈利预测”。不以“模型”“估值模型”“用户模型”作主语（如“模型隐含”“模型要求”“模型预计”），方法与模型来源在“盈利预测与估值”方法段或附录交代一次。
- 公司事实写“公司公告/公司披露”，第三方数据写机构名，市场数据写“Wind/历史行情”。三者与“我们预计”不混用。
- 不用第一人称以外的口语化主体（如“市场对公司的定价已经超过一份……的模型”），改为“当前股价高于我们的DCF估值25%”。

## 二、标题

| 层级 | 格式 | 示例 |
|---|---|---|
| 报告标题 | 判断式，≤20字，不用引号与感叹 | 硬件优势已兑现，估值已反映远期乐观预期 |
| 一级章节 | `类别：判断`，冒号分隔，≤30字 | 行业格局：人形机器人仍处万台级规模，四足率先实现行业应用 |
| 二级标题 | 判断式短句，不加“XX：”前缀，或使用`对象：判断` | 单位成本下降支撑高毛利率 |
| 图表标题 | `对象＋期间＋（单位）`，描述数据而非下结论；结论放在图前正文 | 2025年全球人形机器人出货量及厂商分布（台） |
| 表格标题 | 同图表；预测表写“盈利预测与估值”“主要财务指标” | 2026年第四季度隐含经营指标 |

图表标题不出现“模型要求”“模型隐含”“预计翻倍”等判断性或过程性措辞；单位放在括号中，多单位时写在坐标轴或表头。

## 三、术语对照（内部用语 → 成稿用语）

| 不用 | 用 |
|---|---|
| 现价 | 当前股价（首次出现注明日期） |
| 基准价值 / 模型价值 / 条件价值 | DCF估值、每股价值、估值中枢 |
| 价值区间 | 估值区间 |
| 压力 / 上行情景 | 悲观 / 乐观情景（中性为基准） |
| 近端证据、短端数据 | 近期经营数据 |
| 反证、失效条件、论点卡 | 风险、需跟踪的关键指标（底稿用语不进成稿） |
| 补算、补充测算、团队补算 | 我们测算（方法在附注交代） |
| 隐含要求 | 隐含假设 / 所需达到的水平 |
| 上修/下修空间“再高四分之一” | 上调25%（用数字，不用分数口语） |
| 买家、热度、撑起、跑出来、拉满 | 客户、关注度/景气度、支撑、实现、充分 |
| 先行参照 | 可比先例 |
| 毛利空间收窄 | 毛利率下行 |

“预期差”“兑现”“景气”“量价”“口径”“同比/环比”“个百分点”是行业通用词，可以使用。

## 三之二、常用句式（参照公开卖方报告的表达习惯）

- 封面要点：`判断句。1）依据一；2）依据二。`——首句加粗，后文用“1）2）3）”分点，不另起小标题。
- 业绩与预测：“我们预计公司2026/2027/2028年实现营业收入27.9/47.7/75.4亿元，归母净利润6.4/9.7/14.9亿元，对应PS分别为90.7/52.9/33.5倍。”多年数据用斜杠并列，单位只写一次。
- 同比环比：“同比增长55.7%，环比下降4.0个百分点”；区间预告写“41.60亿元–45.60亿元，中值为43.60亿元”。
- 归因：“主要系……所致”“受益于……”“有望……”；判断强度依次为“预计/有望/或将”，没有依据不用“必将”“确定性”。
- 事件点评结构：`事件：`→分点分析→`投资建议：`→`风险提示：`；深度报告封面用“投资要点”，末段写估值结论。
- 风险提示：一句话列举，用分号或顿号分隔，如“风险提示：产能扩建不及预期；产品研发不及预期；客户拓展不及预期。”正文风险表再写触发条件与影响。
- 行业与公司称谓：首次出现写全称加代码，其后称“公司”；同业写简称。

## 四、数字与单位

- 金额默认“亿元”；单位写在括号里：“营业收入（亿元）”“销量（台）”“毛利率（%）”。表头年份用`2025A/2026E`，季度用`2026Q3`、`2026Q4E`。
- 比例变化用“个百分点”；增速写“同比增长55.7%”；倍数写“52.9倍”；区间用“414–637元”（en dash）。
- 失真倍数写N/M；不在正文引用“374倍市盈率”之类失真数字，必要时写“市盈率不具可比性”。
- 不用“约”叠加精确小数（“约499.6元”），精确值直接写，概数写整数。

## 五、资料来源

- 格式：`资料来源：公司公告，Omdia，示例研究`——机构之间用中文逗号，研究机构自身放最后。
- 配置了研究名称时，“团队分析”“估值模型”统一显示为研究名称（我们的预测与测算即本机构研究）；未配置时显示“团队分析”。
- 来源只写机构名，不写报告标题、页码、URL、模型工作表。

## 六、固定栏目名称

封面：投资要点、公司资料、股价表现、估值摘要、风险提示、主要财务指标。正文末章：风险提示（含触发条件与影响）、催化剂。附录：盈利预测与估值附表、重要声明。
