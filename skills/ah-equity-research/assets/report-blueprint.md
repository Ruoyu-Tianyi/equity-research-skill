# 中文深度研报结构蓝图

研究优先蓝图。生成前先形成有来源的章节主张，再使用本骨架；不能交付空白框架或将模型核查事项替换成章节。正文按行业格局→公司竞争力→投资逻辑→盈利估值展开，首页提前提炼结论。篇幅由研究问题和证据决定；视觉主题调整不改变这一研究主线。

| 位置 | 读者需要获得的内容 | 图表与附录衔接 |
|---|---|---|
| 首页 | 公司/代码/市场、截止日、结论式标题；行业变化、公司优势、主要盈利驱动与估值判断；风险 | 紧凑预测表、完整估值摘要；有核实行情才放现价/走势 |
| 行业格局 | 市场边界与规模、分终端需求、供给与成本、集中度/竞争分工、价格周期 | 独立行业规模、供需/价格、份额与需求结构图；注明统计/预测 |
| 公司竞争力 | 商业模式与利润来源；产品/客户、成本/效率、技术/渠道、资本配置相对同行的优势和短板 | 公司/同行可比指标、产品/业务结构、单位经济、发展阶段证据 |
| 投资逻辑 | 少量具体主张，用比较数据说明公司受益程度，解释量价、结构或成本对利润的影响 | 关键驱动桥、验证指标；避免重复首页或把论点全画成流程图 |
| 盈利预测 | 从经营驱动解释收入、利润率、费用、资本开支与现金转换；模型承担量化 | 分部量价/份额、利润桥、盈利质量及预测摘要 |
| 估值与市场预期 | 原模型方法适用性、价值形成、同行或独立比较；现价隐含的经营要求 | 核心参数、每股价值桥、可比表、反向估值/隐含条件 |
| 情景与敏感性 | 经营争议如何改变盈利与价值；牛/基准/熊条件彼此经济一致 | 有经营含义的敏感性矩阵/情景图，与现价同币种同日期比较 |
| 催化与风险 | 可观察事件、预计期间、验证指标，以及关键变量下修对盈利或估值的影响 | 催化表和风险变量表 |
| 经营与财务附录 | 模型实际具备的量价、产能/销量、产品结构、成本/利润率、资本开支/折旧、营运资本及预测三表 | 按经济关系分组；正文保留主要驱动，附录展示重要明细；不伪造缺失三表 |
| 估值附录 | 关键参数、股权/每股价值桥、情景与敏感性、必要财务口径 | 提供可理解的公式与数值，不展示单元格坐标；不重复正文已完整呈现的表 |
| 研究补充附录 | 正文未充分展开的终端/客户/渠道结构、成本投入品、研发构成、同行/行业分项等有价值数据 | 每组有研究含义、单位、时点与简短来源；按公司选择，避免资料堆积 |
| 内部support底稿 | 完整URL、来源ID与页码、模型版本和单元格映射、补算、技术审计/外链/工具权限及检查日志 | 过程自述不进入成稿；重要假设、测算身份与实质风险在正文或集中方法表交代一次 |

首页预测表常用列为最近2个实际年度与3个预测年度；沿用模型实际范围，不延长预测凑列。常用行为收入、增长、归母利润、EPS、ROE、PE/PB或行业适用指标。表内写明货币和金额单位，A/E标识明确。

各节按 [专业行文](../references/writing-style.md) 先给具体判断，再用可比数据和产业机制解释经营结果；本表是内容分工，不是可原样使用的章节标题。只保留影响判断的反证条件与风险，预测、测算和事实的身份仍准确。模型检查只影响结论的可信范围，不能成为全文叙事。行业和公司研究不能都由预测表代替，估值也不能与经营机制脱节。

图表下只保留简短资料来源：纯原创分析为“资料来源：团队分析”，使用用户模型为“资料来源：估值模型、团队分析”，公开事实保留真实公告或机构简名。来源行不附解释注、免责、单位、预测或口径说明；必要单位、期间、分母与A/E写入图内、标题或表头，重要研究假设在正文/方法表交代一次。
